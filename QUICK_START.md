# ⚡ Быстрый старт

## 🚀 Как запустить

1. Откройте файл `osi-guide.html` в браузере (двойной клик или правый клик → открыть с браузером)
2. Всё! Справочник готов к использованию 🎉

## ➕ Добавить новый протокол за 30 секунд

1. Откройте `osi-guide.html` в текстовом редакторе (VS Code, Notepad++, Sublime Text)

2. Найдите строку примерно на позиции **линия 170**:
   ```javascript
   const protocols = [
   ```

3. Перейдите в конец массива (перед `];`)

4. Добавьте новый протокол. Пример для HTTP/3:

```javascript
{
    name: "HTTP/3",
    layer: 7,
    description: "Новое поколение HTTP. Использует QUIC протокол для лучшей производительности.",
    port: "443",
    function: "Веб-приложения (новое поколение)",
    uses: "QUIC",
    fullDescription: "HTTP/3 основан на QUIC и предоставляет более быструю загрузку страниц, особенно при потере пакетов и высокой задержке."
}
```

5. Сохраните файл (Ctrl+S)

6. Обновите страницу браузера (F5 или Ctrl+R)

7. Ваш новый протокол появился! ✅

## 🎨 Быстро изменить цвет

Найдите в файле:
```css
:root {
    --primary: #6366f1;
```

Замените `#6366f1` на другой цвет:
- 🔴 Красный: `#ef4444`
- 🟢 Зелёный: `#10b981`
- 🟠 Оранжевый: `#f97316`
- 🟣 Фиолетовый: `#a855f7`
- 🔵 Синий: `#3b82f6`

## 🌙 Включить тёмный режим по умолчанию

Найдите:
```javascript
function loadTheme() {
    const theme = localStorage.getItem('theme') || 'light';
```

Замените `'light'` на `'dark'`:
```javascript
function loadTheme() {
    const theme = localStorage.getItem('theme') || 'dark';
```

## 📋 Структура протокола - шаблон

Копируйте и заполняйте:

```javascript
{
    name: "НАЗВАНИЕ",              // Аббревиатура или название
    layer: 7,                        // Уровень (1-7)
    description: "Короткое описание",
    port: "123",                     // Номер порта или N/A
    function: "Функция",             // Что делает
    uses: "Использует",              // На каком протоколе
    fullDescription: "Полное описание с деталями."
}
```

## ✏️ Примеры добавления протоколов

### Пример 1: Протокол уровня 7 (DNS)
```javascript
{
    name: "DNS",
    layer: 7,
    description: "Система доменных имён. Преобразует доменные имена в IP адреса.",
    port: "53",
    function: "Разрешение имён",
    uses: "UDP/TCP",
    fullDescription: "DNS преобразует человеко-читаемые доменные имена (google.com) в IP адреса."
}
```

### Пример 2: Протокол уровня 3 (EIGRP)
```javascript
{
    name: "EIGRP",
    layer: 3,
    description: "Протокол динамической маршрутизации корпоративного класса.",
    port: "88",
    function: "Маршрутизация",
    uses: "IP",
    fullDescription: "EIGRP - улучшенный вариант RIP с лучшей сходимостью и меньшим потреблением полосы пропускания."
}
```

### Пример 3: Протокол уровня 2 (RSTP)
```javascript
{
    name: "RSTP",
    layer: 2,
    description: "Быстрый протокол покрывающего дерева. Улучшенная версия STP.",
    port: "N/A",
    function: "Быстрое управление топологией",
    uses: "Ethernet",
    fullDescription: "RSTP обеспечивает более быструю конвергенцию, чем стандартный STP, снижая время восстановления при сбое линии."
}
```

## 🔍 Поиск строк для редактирования

2. Введите текст для поиска
3. Перейдите к результату

### В браузере (консоль):

```javascript
// Введите в консоль (F12):

```

## 📱 Проверить на мобильном

1. На ПК откройте браузер
2. Нажмите **F12** для инструментов разработчика
3. Нажмите **Ctrl+Shift+M** (или значок смартфона)
4. Выберите размер устройства

## 🐛 Если что-то сломалось

1. Проверьте синтаксис - все запятые, скобки, кавычки на месте
2. Откройте консоль (F12) - там будут ошибки
3. Восстановите оригинальный файл с GitHub
4. Начните заново
