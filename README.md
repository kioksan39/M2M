# 🌐 Справочник протоколов OSI

Интерактивный справочник для изучения протоколов модели OSI с красивым интерфейсом и визуальной диаграммой.

## ✨ Особенности

- **Визуальная диаграмма 7 слоёв OSI** - интерактивные блоки каждого слоя
- **Красивые карточки протоколов** - с полной информацией о каждом протоколе
- **Поиск и фильтрация** - быстрый поиск по названию и уровню OSI
- **Тёмный режим** - удобное чтение в любое время
- **Полная адаптивность** - работает на мобильных и десктопных устройствах
- **Модальные окна** - подробная информация о каждом протоколе

## 📂 Файлы

- **osi-guide.html** - Основной интерактивный справочник (рекомендуется)
- **исход** - Оригинальный файл
- **PROTOCOL_GUIDE_EDITED.html** - Альтернативная версия

## 🚀 Использование

Просто откройте файл `osi-guide.html` в вашем браузере. Никаких зависимостей не требуется!

### Функции:

1. **Фильтрация по уровню** - нажмите на кнопку уровня или на саму карточку слоя
2. **Поиск** - введите название протокола в поле поиска
3. **Просмотр подробностей** - кликните на карточку протокола
4. **Смена темы** - нажмите кнопку в верхнем углу

## 📊 Структура протоколов

### Уровень 7 (Приложение)
- HTTP/HTTPS, SMTP/POP3/IMAP, DNS, FTP, SSH, TELNET, SNMP, DHCP, NTP, BGP

### Уровень 4 (Транспорт)
- TCP, UDP, SCTP, DCCP

### Уровень 3 (Сеть)
- IP (IPv4/IPv6), ICMP, IGMP, GRE, IPSec, RIP, OSPF

### Уровень 2 (Канал данных)
- Ethernet, Wi-Fi (802.11), PPP, ARP, VLAN, Spanning Tree

### Уровень 1 (Физический)
- Twisted Pair, Fiber Optic, Coaxial Cable, Radio Waves

## 🛠️ Как добавить новый протокол

Откройте файл `osi-guide.html` и найдите массив `protocols`. Добавьте новый объект:

```javascript
{
    name: "Название протокола",
    layer: 7,  // Уровень OSI (1-7)
    description: "Краткое описание",
    port: "80",  // Номер порта или N/A
    function: "Функция протокола",
    uses: "Используемый протокол",
    fullDescription: "Полное описание с деталями"
}
```

Сохраните файл и обновите страницу браузера. Новый протокол появится на странице!

## 🎨 Как изменить стиль

В файле `osi-guide.html` найдите блок `<style>`:

1. **Цвета** - измените переменные в `:root`:
   ```css
   :root {
       --primary: #6366f1;  /* Основной цвет */
       --bg-light: #f8fafc;  /* Фон светлого режима */
       --bg-dark: #0f172a;   /* Фон тёмного режима */
   }
   ```

2. **Шрифты** - измените `font-family` в `body`

3. **Размеры** - измените значения `font-size`, `padding`, `margin`

4. **Анимации** - модифицируйте `@keyframes` блоки

## 💡 Примеры кастомизации

### Изменить основной цвет на синий:
```css
--primary: #3b82f6;
--primary-dark: #2563eb;
```

### Изменить основной шрифт на Georgia:
```css
font-family: Georgia, 'Times New Roman', serif;
```

### Изменить переход при наведении на карточку:
```css
.protocol-card:hover {
    transform: scale(1.05) !important;  /* Вместо translateY */
}
```
