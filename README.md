# Protocol Guide — редактируемый сайт

## Запуск

Распакуйте весь архив и откройте `index.html` в современном браузере. Все скрипты, шрифты и стили включены в архив; npm и сборка для обычных изменений не нужны.

Для разработки рекомендуется локальный HTTP-сервер. В папке проекта выполните:

```sh
python -m http.server 8000
```

Откройте `http://localhost:8000`. Для публикации скопируйте содержимое папки на статический хостинг. Используются относительные пути, поэтому поддерживается размещение в подпапке.

## Где что редактировать

| Файл | Назначение |
| --- | --- |
| `index.html` | Заголовок вкладки, подключение CSS и JS, структура стартовой страницы |
| `css/theme.css` | Основные цвета, фон, шрифт, переопределения оформления |
| `css/base.css` | Полная вёрстка, размеры панелей, адаптивность, анимации, оттенки SVG `--k-*` |
| `css/gre-controls.css` | Кнопки настроек/PNG и форма параметров GRE |
| `css/fonts.css` | Подключение шрифтов через `@font-face` |
| `assets/fonts/` | Файлы WOFF2 — можно заменить или добавить свои |
| `js/config.js` | Начальные APN/IP/P2P и размер, качество, имя PNG |
| `lessons/gre.js` | Полный урок GRE, описания, шаги, события пакетов, декодер заголовков |
| `js/gre-settings.js` | Форма, проверки CIDR/P2P, преобразование адресов и обновление схемы |
| `js/export-png.js` | Получение SVG с экрана, сохранение стилей, компоновка PNG и текста |
| `js/app.js` | Движок сайта, остальные уроки/переводы, HTML панелей, SVG-иконки и расположение узлов |
| `js/export-fonts.js` | Встроенные шрифты для автономного PNG; генерируется вспомогательным скриптом |
| `tools/update-export-fonts.py` | Обновление шрифтов PNG после изменения `fonts.css` или WOFF2 |
| `examples/gre-route.png` | Пример реального экспорта кнопкой сайта |

JavaScript и CSS отформатированы, без минификации. Движок восстановлен из клиентской сборки предыдущей версии сайта; это не официальный исходный репозиторий первоначального проекта. Часть внутренних имён движка остаётся сокращённой. Для GRE и PNG выделены отдельные понятные файлы.

## Шрифт и цвета

1. Измените `--guide-font` и переменные цветов в `css/theme.css`.
2. Для своего шрифта поместите WOFF2 в `assets/fonts/` и добавьте `@font-face` в `css/fonts.css`.
3. После изменения файлов шрифта или `fonts.css` выполните:

```sh
python tools/update-export-fonts.py
```

4. Обновите страницу с очисткой кэша (`Ctrl+F5`).

Для мелких оттенков иконок переопределяйте соответствующие `--k-*` из `base.css` в `theme.css`. Геометрия оборудования задаётся SVG в `app.js`; найдите `class="network"`, `class="gre-only"` или `data-node`.

## GRE

Пять полей доступны через «Параметры GRE». Изменение применяется к схеме, описаниям, таблице и декодеру пакетов. P2P поддерживает две разные пригодные для узлов IPv4 одной /30. Пул SIM не должен пересекаться с P2P и LAN примера.

Начальные значения находятся в `config.js`. Значения, сохранённые через форму, имеют приоритет: для проверки новых значений по умолчанию очистите запись `protocol-guide:gre` в хранилище браузера или используйте новый профиль. Фиксированный узел МТС `217.73.241.91` задаётся преобразованием в `gre-settings.js`. На клиентском маршрутизаторе это `tunnel destination`; на МТС назначение — Public IP клиента.

Адреса-образцы в `lessons/gre.js` используются как шаблоны замен. При изменении этих адресов вручную также обновите таблицу замен в `gre-settings.js`.

## PNG как на сайте

Кнопка «Скачать схему PNG» копирует сам SVG сети с вычисленными стилями. Поэтому сохраняются изометрические иконки, SIM, сетка, цвет, текущие подписи и видимые участки маршрута. Справа добавляются описание и параметры выбранного шага. Текст не обрезается: высота PNG растёт при необходимости.

Для полной топологии вернитесь к обзору GRE. Для выбранного участка выберите шаг, затем используйте «ПУСК»/«ПАУЗА» или «ШАГ», чтобы показать нужный момент. PNG — статичный снимок: если пакет уже завершил движение или ещё не появился на экране, на снимке его также не будет. Экспорт приостанавливает воспроизведение; продолжить можно кнопкой «ПУСК».

Экспортируется сетевой вид, даже если открыта вкладка «Последовательность». Размер и масштаб PNG изменяются в `config.js`, расположение схемы и текстовой колонки — в `export-png.js`. По умолчанию ширина 3000 пикселей (1500 × 2). Изображение создаётся локально в браузере, без внешнего сервиса.

## Проверка после изменений

Проверьте загрузку страницы, переключение GRE/HTTP, применение параметров, прямой/обратный путь пакетов и экспорт PNG. После обновления файлов на сервере используйте `Ctrl+F5`. Не удаляйте отдельные папки: для этой редактируемой версии они нужны при запуске.

Интерфейс русский, GRE первый, начальная тема светлая. Все адреса и пакеты — учебная модель; сайт не выполняет сетевые тесты.
