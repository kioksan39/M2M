ЗАПУСК: откройте index.html в корне архива. Он автономный: все ресурсы встроены.
Папка source — редактируемые исходники.
После изменений из source выполните: python tools/build-standalone.py
После замены шрифтов сначала выполните: python tools/update-export-fonts.py
На телефоне распакуйте ZIP и выберите открытие index.html через Chrome, а не предпросмотр внутри архива.
