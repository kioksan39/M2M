## 🎯 Популярные задачи

### Задача: Изменить основной цвет на красный
**Время: 1 минута**

Файл: `osi-guide.html`
Найти: `:root { --primary: #6366f1;`
Заменить на: `--primary: #ef4444;`
Сохранить и обновить браузер.

### Задача: Добавить новый протокол (например, WebSocket)
**Время: 2 минуты**

1. Откройте `osi-guide.html` в редакторе
2. Найдите `const protocols = [`
3. Скопируйте пример из `PROTOCOL_EXAMPLES.md` (WebSocket)
4. Вставьте перед `];`
5. Не забудьте запятую перед новым протоколом
6. Сохраните и обновите браузер

### Задача: Установить тёмный режим по умолчанию
**Время: 1 минута**

Файл: `osi-guide.html`
Найти: `const theme = localStorage.getItem('theme') || 'light';`
Заменить `'light'` на `'dark'`
